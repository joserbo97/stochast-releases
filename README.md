# Stochast for Excel on Mac

Monte Carlo simulation, forecasting, optimization and about 150 analysis tools inside Excel for Mac. Everything
runs on your Mac; nothing is sent anywhere.

**[Download page](https://joserbo97.github.io/stochast-releases/)** · [All versions](https://github.com/joserbo97/stochast-releases/releases) ·
[Help and feedback](https://github.com/joserbo97/stochast-releases/issues) · [Privacy](https://joserbo97.github.io/stochast-releases/privacy.html)

This repository holds the download page and the installers. To install, download `Stochast-<version>.pkg` from the
latest release and open it; to remove Stochast, open `Uninstall-Stochast.pkg`. Each release lists the installer's
SHA-256 so you can check your download:

```bash
shasum -a 256 ~/Downloads/Stochast-*.pkg
```

Needs macOS 13.5 or later (Apple silicon or Intel) and Excel for Microsoft 365, version 16.50 or later. The installer
is not yet signed by Apple, so macOS asks you to allow it once under System Settings › Privacy & Security ›
**Open Anyway**.
